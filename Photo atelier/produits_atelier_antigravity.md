Pour chaque produit, utiliser cette logique d'affichage :
- Nom du meuble
- Type de meuble
- Zones modifiables
- Matériaux autorisés par zone
- Dimensions
- Notes si une information est absente dans le PDF

## Structure JSON conseillée pour Antigravity

```json
[
  {
    "nom": "Table Basse Perla",
    "type": "table basse",
    "zones_modifiables": [
      {
        "zone": "Plateau",
        "materiaux": ["bois teinte clair", "bois teinte foncé", "marbre"]
      },
      {
        "zone": "Pieds",
        "materiaux": ["bois teinte clair", "bois teinte foncé", "effet béton", "laque couleur"]
      }
    ],
    "dimensions": {
      "diametre": [90, 100, 110],
      "hauteur_cm": 35
    }
  }
]
```

## Notes d'interprétation

- Quand le PDF ne sépare pas clairement les zones, la formulation **meuble entier** a été utilisée pour faciliter l'intégration dans un configurateur [file:1].
- Quand le PDF mentionne **chaque ref** pour le marbre, cela signifie que toutes les références marbre de la cliente sont autorisées pour cette zone [file:1].
- Certaines pages du PDF ne donnent pas de dimensions ; ces champs doivent être complétés plus tard si la cliente les fournit [file:1].
